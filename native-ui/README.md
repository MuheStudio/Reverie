# Reverie 月光观景室

Qt Quick/QML + C++ 的项目内原生开发候选。当前覆盖陪伴、聊天阅读、世界书资料匣、设置终端和角色导入；复用原有 Python/V4、SQLCipher、人格证明与 Native Live2D。当前资料编辑仍为首书首条；其他活动不冒充已完成原生迁移。

2026-10-11 接手提示：先读[Claude Code 接手说明](../docs/CLAUDE-CODE-HANDOFF.md)。当前源码已包含后续诊断工具，旧普通 R3 默认指针不再代表匹配当前输入的候选；以下普通启动示例须先满足候选匹配条件。不要放宽核验或因交接自动重建、重放已耗尽额度的检查。

## 启动、构建和检查

在现有工作树根目录启动：

```sh
./script/dev-qt-macos.sh --disposable
```

读取 `.tools/qt-candidates/last-local-sdk.json`，核对输入/签名后创建新隔离空间，默认配置本机模拟模型。退出会删除本次资料及对应测试钥匙串项，不作为日常持久工作空间。模型从角色入口显式导入，权利与性能确认照常执行。模拟模型不代表真实模型质量。

可用 `--build-dir ABS_DIRECTORY` 选择具体候选。不能通过直接双击 `.app` 绕过隔离上下文；此开发候选依赖当前项目的 Qt、Python、Node 和 SDK 文件，并非独立发行包。

```sh
# 默认不链接 Core；示例名称请换成尚不存在的新候选名
./script/build-qt-macos.sh --candidate moonroom-corefree-next

# 已接受适用条款、仅作本地验证的固定 Native SDK
./script/build-qt-macos.sh \
  --local-sdk "$PWD/.tools/live2d-native/CubismSdkForNative-5-r.4.1" \
  --candidate moonroom-scene-next

# 真实控件、恢复与隔离检查
./script/check-qt-macos.sh --build-dir ABS_DIRECTORY --model ABS_AUTHORIZED_TEST_COPY

# 独立录像批次；不将此批次当作性能采样
./script/check-qt-macos.sh --build-dir ABS_DIRECTORY --model ABS_AUTHORIZED_TEST_COPY --record

# 补充功能盘点：服务、网络暂停、费用许可、形象与偏好；两轮同数据，逐例记录
./script/check-qt-macos.sh --build-dir ABS_DIRECTORY --supplementary

# P0后续：双端点许可同步、停止拒绝/超时、受控暂停；独立两轮同数据
./script/check-qt-macos.sh --build-dir ABS_DIRECTORY --p0-tail

# 带停顿的阅读/任务演示；从Moonroom控件场景开始录制，与快速压力录像分别保存
./script/check-qt-macos.sh --build-dir ABS_DIRECTORY --model ABS_AUTHORIZED_TEST_COPY --record-demo
```

候选名冲突拒绝覆盖。构建记录源码/文件清单、外部依赖和本地测试签名；运行输入不一致时要求明确重建。脚本不升级已有依赖、不改变全局PATH，不引用Codex运行时缓存。Qt官方版本/构建/下载校验值见 `config/qt-macos-toolchain.json`。

检查输出在新的 `.tools/reports/qt-*`；录像仅抓取该实例的 QQuickWindow，使用实际单调时间戳编码 H.264 MOV，不读取其他窗口、不插帧制造操作。录像关闭性能采样，编码失败会使该批次失败。

设计预览 `ScenePreview`（`native-ui/preview/`）用真实场景、聊天、入口和玻璃组件离屏渲染陪伴构图，经 OpenGL 帧缓冲输出 PNG。它不显示窗口、不启动后端或数据目录、不加载 Live2D，因而不能代替应用内检查。它只渲染产品组件和着色器；月下观测台三轮设计探索用过的副本已移除，留在 git 历史中（`6183320`、`f07a2a9`）。`--open memory|memory:reload|settings|chat:reading` 在陪伴落定后打开对应视图（`memory:reload` 再弹出重新读取确认框）；`--hover`／`--focus` 接对象名，在视图落定后把该控件置于悬停或焦点状态；资料匣用真实 `ArchiveDrawer` 配静态编辑器替身，终端只放控件样例，不加载 `TaskPanel`。

```sh
.tools/qt-builds/<目录>/ScenePreview --out "$PWD/.tools/reports/<目录>/current.png"
```

## 三种构图

- **陪伴**：角色站在星盘地台上，模型基线落在星盘中心（`SceneDirector.stageCenter`），占据稳定保留区。宽窗时预览贴在输入台上方，与输入台合成右下对话列，显示当前用户一句和回复最多四行；“阅读全文”进入该回复，普通“历史”恢复原阅读位置。阅读外壳不常驻。
- **阅读**：右侧安全区域内展开，同一个历史控件记录消息ID、UTF-16文本位置、视口偏移、followLatest、选区和光标；任务后即使换行仍恢复原文位置。新回复只提示，点击“回到最新”才离开旧位置。
- **任务**：资料/终端为前景，聊天收为陪伴条，仍能停止当前回复或返回对话；不创建第二输入框。关闭任务回到进入前的陪伴/阅读状态。

宽窗陪伴与阅读共用左中部角色区域；终端挂在右上墙面，资料匣与望远镜在左侧。窄窗（宽度小于1180）阅读采用左侧紧凑角色带与右侧阅读区；资料/设置任务才暂隐角色及命中区域，保留实际模型和动作状态；角色管理仍保留可见形象。最小窗口为760×650。单一输入台随草稿从68增高至144逻辑像素，超出后内部滚动。

## 职责与接口

| 职责 | 实现与边界 |
|---|---|
| 业务 | `RuntimeBridge` 继续拥有单一Python连接、消息/人格/授权/模型任务；`ArchiveEditor` 保存revision、快照、草稿及回执。动画不取消业务任务。 |
| 导航 | `SceneNavigation` 的统一入口登记供物件、导航和搜索使用；保存任务前聊天子态、转场修订号、搜索返回和各功能焦点。 |
| 构图 | `SceneDirector` 输出完整角色保留区、安全矩形、转场来源/目标/修订号和连续进度；阅读使用可反向弹簧，任务进度跟随实际物件，任务切换不短暂回到陪伴。 |
| 连续物件 | `ScenePortal` + `RetargetMotion` 保留位置与速度。资料匣先从下方取出，再展开，避开角色上半身；终端共享机制。把手独占拖动。 |
| 内容输入 | 外壳连续变化，正文在不可见交接区换版式并恢复文本锚点。几何落定即可操作，材质仍可收敛。历史内容恢复不禁用已稳定的导航和草稿框。`InputContext` 为导航提交预编辑，Esc/Enter在组词时不越级触发。 |
| 环境/材质 | 月下观测台：原创程序化房间、观测穹窗、窗景、家具、地板和接触阴影共用锚点/光照，仪器光统一用冷青；望远镜按镜筒坐标绘制部件，并用同一组主光、壁灯暖光和窗口冷边光着色。玻璃外缘的光沿光照方向从受光角平滑过渡；面板内输入框、按钮和分隔线的描边弱于外缘，焦点框保持清晰。窗景（`room-sky.frag`）只覆盖拱窗开口并承载云层漂移；其余（`room.frag`）缓存为全DPR图层，只在几何、转场或入口变化时重绘，以预乘透明露出窗景。资料匣和终端的玻璃面不停靠在槽位时（窄窗、阅读或其他任务中），房间画出合上的抽屉面和待机屏；被取出时仍显示空腔。`MaterialProfiles` 定义clear/work/reading，正文不折射。 |
| 合成 | `LayerCompositor` 按实际绘制顺序生成无环累积背景；仅为参与或被覆盖的表面捕获。玻璃只采背后内容，清晰内容随后绘制。 |
| 角色呈现 | `AvatarSurface` 包装一个NativeAvatar；隐藏是最终合成权重/输入资格变化。模型基准不随动作变化，视图几何与命中一致。 |

合成纹理按实际DPR准备；共享双阶段模糊，底图缓存避免重复绘制。角色FBO及其源纹理只在需要更高分辨率时增长，姿态缩放不逐帧重新分配，也不降到低于当前DPR。缓冲区生命周期与模型/窗口一起结束。

`RuntimeBridge`仍保留其他旧原型接线，不据此宣称所有功能已完成架构迁移。r1补齐了既有V4取消回执的识别；r2没有更改桥接业务或通信命令。未读提示按人格范围与回复轮次登记，即时delivery ID替换为持久消息ID不会重复计数，消息身份和阅读锚点仍使用原业务ID。

## P0 操作反馈与补充检查

回复服务、网络控制、费用操作和聊天各自保留局部反馈；连接提示仍独立显示。暂停或网络状态未确认时不派发聊天，保留输入；排队与生成遵循既有节奏，失败与结果未知不会自动重试。许可行的「许可条件满足」不代表该业务已有原生入口，也不覆盖全局网络暂停。同一模型路径重选保持真实的绘制状态，不强制重载。

`--supplementary` 是显式隔离测试入口，会使用固定的 `tests/p0_backend_bootstrap.py`，核对登记目录、私有传钥管道及本机模拟服务。仅三个预登记合成标记使用受控起始排程；原恢复案例继续原排程和20秒判定。普通启动与完整控件检查仍直接使用 `src/main.py`，不加载该夹具。补充报告分别记录原场景与受控场景、去内容的请求状态、模拟服务实际响应写出/连接关闭；这些记录不证明客户端收到已写出的数据。结束前只导出白名单元数据，不复制原始后端日志。

`--p0-tail` 与旧补充、录像、交互或诊断模式互斥。宿主在隔离上下文登记两个实际拥有的回环端点；测试只允许这两个目的地。停止故障仅对登记合成请求的一次取消命令生效，真实终态不被屏蔽：拒绝走实际错误回执；超时样例只改变该测试标记的起始排程为40秒，保留生产30秒命令期限。输入步骤在原4秒内等待控件真实可输入，不改产品动画或门禁。

配置提交后许可先标为待确认，再读取实际快照；保存结果未知时自动只读核对一次，不重发保存。停止操作反馈与聊天生命周期分开；未确认停止不会清除仍在途的聊天，也不自动重试。

此说明不是追加运行授权；每轮执行额度以当轮计划和台账为准。

## 操作与状态

- 场景物件或底部入口打开资料/设置；⌘K搜索，⌘1陪伴、⌘2资料、⌘3设置。历史由“历史”或对话区入口打开。
- 把手支持连续展开、反向、收起；Esc或resize取消当前拖动。展开后把手位于顶部中央，保留两个方向的鼠标空间。
- 未保存草稿中性显示，保存中/成功/失败/冲突独立反馈；成功样式只来自真实回执。收起不会销毁草稿或中止保存。
- “重新读取”有草稿时需要明确选择；并发revision冲突不会覆盖草稿。启用开关、状态和操作区常驻，只有长正文滚动。
- 减少动态与减少透明是用户选择，不是自动画质降级。减少动态不停止用户主动触发的模型动作。

## 验证边界

原生单测包括ArchiveEditor、AvatarTransform、RuntimeBridge、SceneDirector。真实窗口检查通过QTest鼠标/滚轮/键盘进入已有控件，包含延迟聊天、长历史、独立取消、资料保存与冲突、窄窗、搜索、焦点和重启。

r2几何测试遍历中间进度与反向；真实窗口在afterAnimating检查全部可见聊天/阅读/输入/任务主体与完整角色保留区，另保留r1上半身/工作面检查的历史口径。阴影与关闭的场景物件不作为前景工作面。新增组合路径覆盖旧文选区、非空草稿、任务后新回复、resize与返回，不能以重新输入草稿代替恢复证明。

普通批次分别输出共同转场/拖动节拍及r2新增阅读/伸缩/resize观察。`LayerCompositor.captureDiagnostics`报告请求纹理尺寸和活动捕获数，不是实际GPU分配测量。两种录像模式均关闭这些性能采样，不读取其他窗口。

中文合成提交/预编辑不等于真实系统输入法与候选栏验收。机器坐标检查不等于审美签收。录像与非录像性能样本分开；`frameSwapped`只表示交换节拍，不是GPU耗时或屏幕输入延迟。完整人工体验、全部旧页面迁移、跨用户/跨版本钥匙串和独立发行仍分别验收。

## 来源与分发

Qt6.11.2固定输入、Cubism Native SDK5-r.4.1和Core校验值已登记。Qt模块的适用条款及分发义务须随最终产物核对，见[Qt许可说明](https://doc.qt.io/qt-6.11/licensing.html)。Native Framework/Core的许可和通知保存在本机SDK的LICENSE/NOTICE文件中。

SDK、Core、模型与生成候选留在忽略目录；Core只在显式`--local-sdk`本地候选中链接，不进入默认构建。新增房间与材质均为本项目源代码绘制，没有导入第三方场景资产。

OpenGL仍是唯一已实现的渲染后端；不引入QtQuick3D或Metal/QRhi。根许可证不变，Apache-2.0优先、MIT备选的迁移目标另行完成。本地ad-hoc签名不代表正式分发或公证。
